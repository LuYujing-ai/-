本项目是一套基于 Flask 开发的 B/S 架构停车场管理系统，面向停车场管理员、收费员两类操作人员，整合车位、车辆出入场、收费、用户权限、系统配置全流程管理，兼顾电脑端与移动端适配，实现停车业务线上标准化、自动化管理，解决人工登记计费易错、车位状态无法实时监控、收费数据难以统计对账等问题。
系统启动与部署流程：
1 环境准备：安装依赖（Flask、Flask-SQLAlchemy、Flask-Login、Flask-Bcrypt）。
2 初始化管理员账号：执行init_admin.py，自动创建 admin 账号（密码：admin123）。
3 启动系统：执行run.py，系统自动创建数据库表与默认系统设置，访问http://127.0.0.1:5000跳转至登录页。
4 首次使用：使用 admin 账号登录，修改系统设置（停车场名称、时薪），新增收费员账号（按需），添加车位信息。
